## 알아 둘 것
- 문장은 서버에 남지 않아도 **처리하려고 외부로 나갑니다.** 조건 추출·수정은 Claude API, 간판 인식은 Google Vision API를 씁니다. 긴급으로 판정된 코스 문장은 LLM을 부르지 않습니다.
- 전화번호 바로 앞에 숫자가 있으면 그 숫자까지 함께 가려질 수 있습니다(덜 가리는 것보다 안전한 쪽).
- 이름·여권번호처럼 형식이 일정하지 않은 개인정보는 가리지 않습니다. 관광 요청 문장에 사용자가 직접 적은 경우 30일 동안 남을 수 있습니다.

## 다시 돌리기
서버와 DB를 docker로 띄운 뒤(시험용 로컬 DB만, **공용 DB 금지**):
```
python eval/privacy/check.py <서버 컨테이너> <DB 컨테이너> <DB 이름> <DB 사용자> [--retention]
```
`--retention`은 서버를 `APP_RETENTION_CRON="*/5 * * * * *"`로 띄웠을 때만 씁니다. 평소 삭제 시각은 매일 03:30(서버 시각)입니다.
