# docs/spec — SRS·SDD 저장소 사본과 버전 관리 규칙

[공용] 요청: #186(김동현). 문서 담당: 김희찬

## 1. 무엇이 어디에 있나
| 파일 | 내용 | 직접 수정 |
|---|---|---|
| `srs.md` | SRS Word 원본의 자동 변환본 | ❌ (스크립트로만) |
| `sdd.md` | SDD Word 원본의 자동 변환본 | ❌ (스크립트로만) |
| `media/srs/`, `media/sdd/` | 원본 안의 그림 | ❌ (스크립트로만) |
| `VERSIONS.md` | 버전별 날짜·작성자·요약·반영한 변경 ID·태그 | ✅ |
| `PENDING.md` | 아직 원본에 반영되지 않은 변경 목록(CHG-NNN) | ✅ |
| `../../scripts/docs/docx2md.py` | 변환 스크립트 | 공용 |

- **원본은 Word(.docx)임.** 제출·발표용으로 팀원이 Word에서 고침
- **md는 사본임.** AI가 구현과 대조하고, 사람이 git diff로 바뀐 곳을 보기 위해 둠
- 원본 파일 자체는 저장소에 올리지 않음(학번 등 개인정보, 용량). 변환 시 원본 sha256을 머리말에 남겨 어떤 파일에서 만들었는지 추적함

## 2. 새 버전을 올릴 때 (문서 담당)
1. Word 원본의 '문서 관리' 표에 새 버전 행을 넣고 저장
2. 변환
   ```
   python3 scripts/docs/docx2md.py srs ~/경로/SRS_v1.5.docx v1.5 2026-12-01
   python3 scripts/docs/docx2md.py sdd ~/경로/SDD_v0.6.docx v0.6 2026-12-01
   ```
3. `VERSIONS.md`에 한 행 추가: 반영한 `CHG-` 번호를 적음
4. `PENDING.md`에서 반영한 항목의 상태를 `반영(SRS v1.5)`로 바꿈. 지우지 않음
5. **한 버전 = 한 커밋**: `docs(spec): SRS v1.4 → v1.5 — <한 줄 요약> (CHG-003, CHG-007)`
6. PR 병합 뒤 태그: `git tag spec/srs-v1.5 && git push origin spec/srs-v1.5`
7. 바뀐 곳 보기
   - `git diff spec/srs-v1.4 spec/srs-v1.5 -- docs/spec/srs.md`
   - 문장 단위로 보려면 `--word-diff`를 붙임

## 3. 구현하다가 명세와 달라졌을 때 (모든 담당·에이전트)
- `srs.md`·`sdd.md`를 **직접 고치지 않음.** 고쳐도 다음 변환 때 덮어씀
- `PENDING.md`에 `CHG-NNN` 항목을 추가하고, 구현 PR과 **같은 PR**에 넣음
- 항목에 적을 것
  - 대상(문서·절·요구사항 ID)
  - 지금 문구 → 바꿀 내용
  - 근거(이슈·PR·커밋)
  - 제안자
  - 상태
- **상태**
  | 상태 | 뜻 |
  |---|---|
  | `제안` | 아직 팀 동의 전 |
  | `합의` | 팀이 정함, 원본 미반영 |
  | `반영(SRS vX.Y)` | 원본에 들어감 |
  | `기각` | 반영하지 않기로 함. 이유를 적음 |
- **`합의` 항목은 원본 문구보다 우선함.** AI가 명세와 구현을 대조할 때는 `srs.md` + `PENDING.md`의 `합의` 항목을 함께 기준으로 봄

## 4. 요구사항 ID 규칙
- ID(FR·NFR·UC·UI·DATA·AI-REQ·COMP·API·AC·TC)는 **번호를 다시 매기거나 다른 뜻으로 재사용하지 않음**
- 삭제한 요구사항은 표에서 행을 지우지 말고 `삭제(vX.Y): 이유`로 남김(예: FR-P021)
- 새 요구사항은 그 파트의 마지막 번호 다음을 씀

## 5. 변환 규칙 (스크립트가 자동으로 함)
- pandoc GFM, 줄바꿈 없음(`--wrap=none`). 병합 셀이 있는 표는 HTML 표로 남음
- 학번(괄호 안 7자리)은 지움. **공개 저장소이므로 개인정보를 넣지 않음**
- 그림 크기 속성은 지움(버전마다 미세하게 바뀌어 diff를 어지럽힘)
- 머리말: `doc`, `version`, `date`, `source`, `source_sha256`, `generated_by`
